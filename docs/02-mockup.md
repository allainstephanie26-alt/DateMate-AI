## Screens

1. Login Screen

Allows users to sign in or create an account before accessing the app. After successful login, the user proceeds to the Home Dashboard.

2. Home Dashboard Screen

Displays the couple's names, date-planning shortcuts, and navigation options. Users can open Couple Preferences, AI Recommendations, or the Bucket List.

3. Couple Preferences Screen

Allows users to select their preferred food, activities, location, and budget. Saved preferences are used to personalize date recommendations.

4. AI Recommendation Screen

Displays date suggestions based on the selected preferences. Users can view place details and save suitable suggestions to their Bucket List.

5. Bucket List Screen

Displays saved date ideas. Users can review their saved places and manage their planned dates.
